About the Project

Understanding Network Flow Optimization

Network Flow Optimization System

The Network Flow Optimization System is a web-based application designed to model, analyze and optimize the flow of resources through a network.


The system represents a network using nodes and directed connections. Each connection can have a specific capacity and cost. The system applies graph algorithms to determine the maximum possible flow between a source and destination.

Project Objectives

  • Create and manage network nodes.
  • Add connections with capacity and cost.
  • Calculate maximum network flow.
  • Identify network limitations.
  • Visualize and analyze network data.
  • Improve network resource utilization.

Algorithms Used

Ford-Fulkerson

Used to calculate the maximum flow between a source and destination.

Edmonds-Karp

Uses Breadth First Search to find augmenting paths in the network.

BFS

Used to search paths through the residual network.

Graph Theory

Nodes and edges are used to represent the network structure.
